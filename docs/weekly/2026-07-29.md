# Week 12: A Quiet Cluster and a Fourth Node

*Covers roughly 23 - 29 July 2026.*

Not much cluster work this week. I had an interview with TikTok, so most of my time
went into LeetCode practice. The cluster mostly looked after itself, which is a good
sign, but it also showed how much I am still relying on checking it by hand.

## 1. Cluster status

Nothing broke. Daily manual checks showed normal temperatures and utilisation on
every node.

The problem is the word "manual". There is still no alerting, so the only reason I
know things are fine is that I looked. That needs to change soon, before a week comes
along where I do not look.

## 2. A new node

I bought another machine: an **Intel NUC with an i5-10210U and 16GB of RAM**. It
worked out of the box and Ubuntu Server is installed on it. It later joins the
cluster as **sol**.

I am deliberately not joining it to K3s yet. The plan is to get a fifth node first
and bring both in together, because a cluster with an even number of servers is
worse than one with an odd number (see Week 10).

One rule for these two nodes: **they get set up with Ansible, not by hand.** The
first three nodes were configured manually over SSH, which was fine for learning the
steps. Doing it twice more by hand is just toil, and every hand-built node ends up
slightly different from the others.
